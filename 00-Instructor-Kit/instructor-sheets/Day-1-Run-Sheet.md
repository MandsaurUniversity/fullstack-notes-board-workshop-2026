## Cut lines (if you are running late)

1. Skip Part 10 (dev tools). Do it as a two-minute demo on Day 2.
2. Give the About page as a copy-paste from the `done` folder, and ask students only to change their details.
3. Move the quiz to the first 10 minutes of Day 2.

Do not cut: the concept talk (frontend, backend, database), the edit-save-refresh loop, the backup, and the homework.

## Concept talk: points to say out loud

- The web is a conversation: request, response.
- Frontend is the dining room, backend is the kitchen, database is the storeroom.
- HTML is the walls, CSS is the paint, JavaScript is the electricity.
- A computer is not magic. It does exactly what the files say.
- Mistakes are normal. Developers make mistakes all day. The skill is finding and fixing them.

## Common problems (see the Stuck Sheet)

- File saved as `index.html.txt` because extensions were hidden.
- CSS not linked or saved in the wrong folder.
- Forgetting to save, or forgetting to refresh.
- Missing closing tags.
