# Day 5: Deploy and Wrap-Up

**Goal:** Students make three small final changes to the Notes Board, push them to GitHub, put the app on the internet with Render (a hosting service), learn honestly what the Free plan can and cannot do, and show their work to the class.

## Highest risk of the day

Two things are **not verified**: whether Render lets every student sign up and create a Free web service (card, phone number and sign-up limits per network are not confirmed), and how long a first deploy takes. Do the throwaway deploy in `../INSTRUCTOR-PILOT-CHECKLIST.md` (Pilot D) before this class. If sign-up fails, students stay at Tier 2 (pushed to GitHub) and you deploy one shared demo on the projector. The Run Sheet has the plan.

## Success tiers

1. **Tier 1:** the Notes Board works on the student's own computer. This is the pass condition.
2. **Tier 2:** the code is pushed to GitHub.
3. **Tier 3:** the app is live on Render with a public link.

## After the workshop

1. Keep your GitHub repository. It is your proof of work. Do not put a password in it.
2. If your Render service is still running, check it once in a while. Remember that it forgets its notes when it restarts.
3. Practise more JavaScript. Change one small thing in the Notes Board each week.
4. Read the "What to learn next" list in `notes/Day-5-Theory`.
5. Do the extras in the lab sheet that you did not finish.
