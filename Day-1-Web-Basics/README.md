# Day 1: How the Web Works, HTML and CSS

**Goal:** Students understand the web in simple words, and build a styled Notes Board home page and an About page. No software installation is needed today.

| Folder | Files |
|--------|-------|
| `notes/` | `Day-1-Theory` (read before class) |
| `lab/` | `Day-1-Lab-Sheet` (13 parts, numbered 0 to 12) |
| `help/` | `Day-1-Stuck-Sheet` |
| `starter/` | An empty page skeleton, and `css/extra-styles.css` (copied into `style.css` in Part 8c) |
| `done/` | The finished `notes-board` folder at the end of Day 1 |

## Homework that Day 2 depends on

1. Students collect the installers into `Workshop-Installers` (see `../00-Instructor-Kit/installer-kit`).
2. Students create a GitHub account at home.
3. Students write down their questions.
